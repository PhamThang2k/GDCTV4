Sao lưu Cơ sở Dữ liệu Hệ thống

Tải toàn bộ dữ liệu bài giảng GDCT, slide, tài liệu đính kèm, ngân hàng câu hỏi và danh sách hồ sơ quân nhân ra tệp tin JSON an toàn.

Phục hồi & Nạp Cơ sở Dữ liệu

Nạp tệp tin JSON cấu hình bài giảng và danh sách quân nhân từ Phòng Tuyên huấn Vùng 4 hoặc khôi phục dữ liệu từ bản sao lưu trước.

Hướng dẫn Đồng bộ Cổng Web Quản trị với Ứng dụng Di động

Hệ thống Cổng Quản trị Web CMS này hoạt động độc lập trên mọi trình duyệt web máy tính của cán bộ tuyên huấn, trợ lý chính trị các cấp. Dữ liệu bài giảng và tài khoản được chuẩn hóa JSON theo cấu trúc Room Database của ứng dụng Android GDCT Vùng 4 Hải Quân, cho phép trích xuất hoặc đẩy dữ liệu tự động.
